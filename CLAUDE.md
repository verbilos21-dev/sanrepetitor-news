# Лента новостей sanrepetitor.ru — правила для Claude

Каждое утро сюда добавляются 1–2 реальные новости России, полезные для ОГЭ/ЕГЭ по обществознанию.
Сервер сайта читает `news.json` (raw.githubusercontent.com/verbilos21-dev/sanrepetitor-news/main/news.json) раз в 30 минут.
Новые id становятся черновиками, Сан одобряет их сам. Уже опубликованные записи не меняй и не удаляй — сервер их всё равно не перечитывает.

## Как добавить новость
- Дописывай в КОНЕЦ массива в news.json. Храни в файле только последние 30 записей (старые удаляй с начала).
- Перед добавлением проверь, что такой новости ещё нет (по смыслу, не только по id).
- Поля: id (дата-слова латиницей, `^[a-z0-9-]{6,80}$`, напр. `2026-10-17-klyuchevaya-stavka`), day (YYYY-MM-DD — дата события),
  block (man|soc|eco|pol|law), title, lead (1–2 предложения), body (2–4 абзаца массивом), oge, ege, example (готовый пример для задания 25,
  с конкретикой: кто, что, когда), topics (2–5 тем кодификатора), source_name, source_url (https), image_url, image_credit.
- Пиши простым русским языком для школьника, без жаргона. Пересказывай своими словами — НЕ копируй текст источника.

## Что брать
- Только реальные события последних 1–3 дней. Каждый факт проверяй по источнику, ничего не додумывай.
- Источники: kremlin.ru, government.ru, duma.gov.ru, council.gov.ru, cbr.ru, rosstat.gov.ru, publication.pravo.gov.ru, а также
  государственные агентства (ТАСС, РИА Новости, ПРАЙМ, «Российская газета»). В source_url — ссылка на конкретную новость.
- Темы: новые законы и их путь (чтения, СФ, подпись Президента), решения ЦБ (ключевая ставка, инфляция), Росстат (безработица, ВВП),
  налоги, бюджет, социальная политика, права граждан, выборы (только процедура), международные договоры.
- НЕ брать: скандалы, оценки политиков, военные действия, происшествия, всё спорное и оценочное. Тон нейтральный.

## Картинки
- image_url — только фото с kremlin.ru или government.ru (лицензия CC BY 4.0), image_credit: «Пресс-служба Президента России, kremlin.ru» / «Правительство России, government.ru».
- Если подходящего фото нет — оставь image_url и image_credit пустыми, сайт поставит обложку сам.

## Объяснение для экзамена
- oge: в каких темах ОГЭ пригодится (блок «Тема»: что именно).
- ege: какие темы/задания ЕГЭ (полномочия органов власти, функции ЦБ, виды налогов и т.д.), можно указать статьи Конституции — только если точно уверен.
- example: одно-два предложения, которые ученик может почти дословно вставить в задание 25 как пример из жизни России.
