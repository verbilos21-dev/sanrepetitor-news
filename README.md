# Новости для ОГЭ и ЕГЭ — sanrepetitor.ru

Лента черновиков для раздела «Новости» на https://sanrepetitor.ru/#novosti.
Сервер сайта раз в 30 минут читает `news.json` отсюда, новые записи становятся черновиками,
Сан одобряет их кнопкой в боте @sanrepetitorbot или в кабинете. Без одобрения на сайте ничего не появляется.
